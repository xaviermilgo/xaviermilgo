What I built.

I built GemGunner to make Ethereum contracts searchable and comparable. The original system collected and analysed more than 70,000 contracts.

I owned the path from finding deployments and retrieving verified source to indexing the results and making them useful in a discovery interface.

The skills behind it.

  • Go + Ethereum

    Collect contract deployments, retrieve verified source and prepare contracts for analysis.

  • Elasticsearch

    Index contracts and their extracted features for search and comparison.

  • React

    Build the discovery interface and source-code views.

How it works.

  1. Find deployments

    Start with contracts deployed directly by externally owned accounts, rather than treating every factory-created contract as a separate discovery.

  2. Retrieve and compare

    Collect available source and metadata, then extract features that make contracts comparable. Missing source or ABI data stays explicitly unavailable.

  3. Make unusual patterns searchable

    Index the results for discovery. The frozen demo also exposes available ABI function findings and rarity scores, so users can inspect the evidence behind a result.
