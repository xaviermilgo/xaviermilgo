What I built.

I built the data pipeline and interactive interface for exploring Solana token ownership. The work covered more than two million wallet relationships.

The challenge was turning a large collection of addresses and balances into a view people could navigate, while keeping the underlying data accessible.

The skills behind it.

  • Node.js + Dune

    Collect and prepare token-holder data for the application.

  • Elasticsearch

    Index wallet relationships for lookup.

  • React + D3

    Render interactive ownership maps and connect visual exploration to holder data.

How it works.

  1. Collect ownership data

    Query token balances and holder records, then normalise the results for the product.

  2. Prepare the data for exploration

    Index the records so the interface can retrieve the relevant ownership information without asking users to navigate raw chain data.

  3. Make the map useful

    Show ownership visually, with node size representing relative holdings. Let users inspect individual holders alongside the wider distribution.
